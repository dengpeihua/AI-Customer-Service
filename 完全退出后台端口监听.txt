要彻底退出，请以管理员身份打开 PowerShell，执行：
```powershell
$root='C:\Users\16332\Desktop\AI-Customer-Service'; Get-CimInstance Win32_Process | Where-Object { $cmd=[string]$_.CommandLine; $exe=[string]$_.ExecutablePath; ($cmd -match 'run_(backend|mem0|widget)\.py') -and (($cmd.IndexOf($root,[StringComparison]::OrdinalIgnoreCase) -ge 0) -or ($exe.IndexOf($root,[StringComparison]::OrdinalIgnoreCase) -ge 0)) } | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
```
这会关闭 AI 客服工作台、后端和 Mem0，但不会退出微信或企业微信。
